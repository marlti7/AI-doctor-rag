
## 用户登录
---
#### 登录接口： userlogin

### 接口地址： /userlogin



#### 请求参数说明

| 请求参数 | 类型 | 必填 | 参数说明 | 示例 |
| :--- | :--- | :--- | :--- | :--- |
| phoneNumber | String | true | 登录用户手机号 |carozhu |
| password | String | true | 登录密码   |123456   |
| confirmPassword | String | true | 确认登录密码   |123456   |


#### 返回参数说明

| 返回参数 | 参数类型 | 参数说明 |
| :--- | :--- | :--- |
| code | Integer | 200：成功|
| accessToken | String | 用户token|
| ... | ... | ... |

#### 返回示例JSON

```json
{
    "responseCode": 200,
    "data": {
        "name": "carozhu",
        "type": 4,
        "version": "1.2.4",
        "md5": "6ed86ad3f14db4db716c808cfc1ca392",
        "description": "update for simple to you！"
    }
}
```
